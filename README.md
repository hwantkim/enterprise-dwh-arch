# 대규모 배포를 위한 데이터 웨어하우스 아키텍처 설계

## 과정 개요
대규모 데이터 웨어하우징 배포를 위한 **성능 최적화, 비용 제어, 보안**을 다루는 심화 과정입니다. 수백~수천 명의 사용자에게 서비스하는 Databricks 환경을 기준으로, 수집·저장 → 워크스페이스 → 보안 → ID의 4개 섹션으로 구성됩니다.

## 섹션 구성

| 섹션 | 주제 | 구성 |
|------|------|------|
| 1. 수집 & 저장 | Lakehouse 기초, 메달리온 아키텍처, Lakeflow 파이프라인, Lakehouse Federation | 요약 3 + 데모 1 |
| 2. 워크스페이스 | 계정 계층, 다중 워크스페이스 전략, Unity Catalog 설계, Delta Sharing | 요약 4 |
| 3. 보안 | 네트워크 보안, CMK, RBAC/ABAC, 세분화된 액세스 제어 | 요약 2 + 데모 1 |
| 4. ID | IdP 페더레이션, SCIM, DABs/GitOps, 감사 로그, 비용 귀속 | 요약 3 + 데모 1 |

## 섹션별 노트북

### 섹션 1: 효율적인 데이터 수집 및 저장
- 1.1 대규모 데이터 아키텍처 소개
- 1.2 대규모 데이터 웨어하우스 수집
- 1.3 데모 - Lakeflow SDP를 사용한 대규모 수집 및 변환
- 1.5 Lakehouse Federation 및 Foreign Catalogs

### 섹션 2: 다중 워크스페이스 전략
- 2.1 Databricks 계정 및 워크스페이스 개요
- 2.2 다중 워크스페이스 아키텍처 설계
- 2.3 대규모 환경을 위한 Unity Catalog 아키텍처 설계
- 2.4 대규모 환경에서의 데이터 공유

### 섹션 3: 대규모 보안 및 거버넌스
- 3.1 데이터 웨어하우스 엔터프라이즈 보안
- 3.2 Unity Catalog를 사용한 데이터 보안
- 3.3 데모 - Unity Catalog에서 FGAC 구현하기

### 섹션 4: ID 및 관리
- 4.1 Databricks Identities
- 4.2 엔터프라이즈에서 Databricks 솔루션 배포
- 4.3 데모 - DABs를 사용한 솔루션 배포
- 4.4 Databricks 감사 및 모니터링

## 대상 청중
플랫폼 관리자, 데이터 웨어하우스 아키텍트, 데이터 엔지니어, 보안 엔지니어

## 사전 요구 사항
Databricks serverless SQL 웨어하우스 실무 지식, Unity Catalog 기초, 클라우드 인프라 기본 개념

---

총 4개 섹션에 15개 노트북(강의 12 + 데모 3)으로 구성된 과정입니다. 각 섹션은 순차적으로 수집·저장 → 워크스페이스 → 보안 → ID 주제를 다루며, 마지막에 0 - 필수 설정 노트북으로 사전 환경 구성을 지원합니다.

> 내용을 zip으로 다운 받으신 후, 데이터브릭스 워크스페이스에서 import 하여 살펴보세요!
> 데모의 경우 Databricks Free Edition에서 실행 가능하도록 코드를 정리하여 제공합니다.
